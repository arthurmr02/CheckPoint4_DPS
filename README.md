

# Checkpoint 4: Differentiated Problem Solving - Limites, Desempenho de APIs e Streamlit
 
Este repositório contém o projeto aplicado de modelagem matemática desenvolvido para a cadeira de Differentiated Problem Solving. O objetivo é analisar o comportamento do tempo de resposta de uma API à medida que a carga de requisições aumenta, utilizando limites para investigar as regiões críticas.

**Curso:** Engenharia de Software  
 
## Estrutura do Repositório
 
O repositório está organizado com os seguintes ficheiros principais:
 
* **`checkpoint.ipynb`**: O documento principal do projeto. É um Jupyter Notebook que atua simultaneamente como relatório técnico, desenvolvimento matemático, código-fonte da análise em Python e evidência visual dos resultados.
* **`app.py`**: O código-fonte da aplicação interativa desenvolvida em Streamlit (gerado automaticamente através do notebook).
* **`requirements.txt`**: Ficheiro com a lista de todas as bibliotecas e dependências necessárias para executar os códigos.
